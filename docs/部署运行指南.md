# ClipFetch 部署运行指南

## 一、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| JDK | 21+ | 后端运行环境 |
| Node.js | v24+ | 仅前端打包开发需要（生产部署可不装） |
| 操作系统 | Windows 10/11 / Linux / macOS | 本指南以 Windows 为例 |

## 二、部署方式（后端 jar + 前端静态资源，分开部署）

当前项目结构：后端打包为独立 `app.jar`（**不含前端页面**），前端需单独构建并用静态服务器/Nginx 托管，通过反向代理转发 `/api` 和 `/ws` 到后端。

### 2.1 获取部署包

项目根目录已包含：

```
clipfetch/
├── app.jar              # 可部署后端 fat jar（约 245MB，含全部依赖）
├── .env                 # 配置文件（数据目录、端口、数据库、代理等）
├── start.bat            # Windows 启动脚本（项目根目录启动）
├── install.bat          # 一键写入系统环境变量（管理员权限）
├── uninstall.bat        # 移除系统环境变量
├── data/                # SQLite 数据库默认存放目录（自动创建）
├── downloads/           # 默认下载目录（自动创建）
└── deploy/              # 可选：预置工具包（yt-dlp/ffmpeg/deno/aria2/jdk21）
```

> **注意**：`app.jar` 是从 `backend/target/app.jar` 复制过来的产物。每次后端重新打包后，需重新复制更新根目录的 `app.jar`。

### 2.2 首次部署步骤

#### Step 1：安装系统环境变量（推荐）

以**管理员身份**运行：

```cmd
install.bat
```

会写入以下系统变量：
- `JAVA_HOME`、`CLASSPATH`、`Path`（JDK 相关）
- `FFMPEG`、`DENO`、`ARIA2C`、`YTDLP`（.env 通过 `%VAR%` 引用）
- `NODE_PATH`、`NODE_HOME`（Node.js 路径）

安装后**必须重新打开命令行窗口或注销重登**，使环境变量生效。

#### Step 2：配置 .env

项目根目录 [.env](../.env) 是核心配置文件，**优先级高于** `application.yml`。

关键项说明：

```properties
# 启动端口（前端开发时代理默认指向 8081，如需改端口请同步改 vite.config.js）
SERVER_PORT=8081

# 数据库：默认 SQLite（零依赖），如需 MySQL 取消下面注释
# DB_DRIVER=com.mysql.cj.jdbc.Driver
# DB_URL=jdbc:mysql://192.168.1.200:3308/fvd?createDatabaseIfNotExist=true&...
# DB_USER=root
# DB_PASSWORD=xxx

# SQLite 存储路径（默认以启动目录为基准，即项目根目录 data/fvd.db）
# DB_URL=jdbc:sqlite:D:/data/clipfetch/fvd.db

# 出站代理（访问 YouTube/Twitter 等需要）
PROXY_URL=http://127.0.0.1:10808

# 工具路径：%VAR% 引用 install.bat 写入的系统环境变量，也可直接写绝对路径
FFMPEG_LOCATION=%FFMPEG%
JS_RUNTIME_PATH=%DENO%
ARIA2C_PATH=%ARIA2C%
YTDLP_PATH=%YTDLP%

# 临时下载目录：相对路径（以启动目录为基准）或绝对路径均可
DOWNLOADS_DIR=downloads

# CCTV 解密相关
NODE_EXE=node
CCTV_DECRYPT_SCRIPT=src/main/resources/cctv/decrypt_browser.js
```

#### Step 3：启动后端

```cmd
start.bat
```

成功后会看到：
```
[完成] 正在启动 ClipFetch，端口 8081 ...
```

此时后端 API 就绪：`http://localhost:8081/api`

#### Step 4：部署前端

```cmd
cd frontend
npm install
npm run build
```

产物在 `frontend/dist/`，用任意静态服务器托管，并将 `/api`、`/ws` 反向代理到后端。Nginx 示例：

```nginx
server {
    listen 80;
    root D:/release/clipfetch/frontend/dist;

    location /api/ {
        proxy_pass http://127.0.0.1:8081;
        # 视频解析/解密/下载耗时可达数分钟，必须放宽超时
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
        proxy_buffering off;
    }
    location /ws {
        proxy_pass http://127.0.0.1:8081;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

> **可选简化方案**：打包前把 `frontend/dist/*` 复制到 `backend/src/main/resources/static/`，再执行 `mvn clean package`，前端即内嵌进 jar，后端直接提供页面访问，无需 Nginx。

#### Step 5：停止后端

关闭命令行窗口，或在启动窗口按 `Ctrl+C`。

## 三、重新打包更新

修改后端代码后，需重新编译打包并更新根目录的 `app.jar`：

```cmd
cd backend
mvn clean package -DskipTests
```

打包成功后产物在 `backend/target/app.jar`，手动复制到项目根：

```cmd
copy backend\target\app.jar app.jar
```

然后重新启动。

## 四、前端开发模式（仅开发时使用）

生产部署按上文 Step 4 用 Nginx 托管 `dist/`；开发调试时：

```cmd
cd frontend
npm install
npm run dev
```

前端开发服务器运行在 `http://localhost:5173`，API 请求通过 Vite 代理转发到 `http://localhost:8081`（代理配置在 `vite.config.js`）。

## 五、常见问题

### Q1：提示 "app.jar 中没有主清单属性"

你复制的是 `target/app.jar.original`（约 3MB，无依赖，不可直接运行）。请复制 `backend/target/app.jar`（约 245MB）。

### Q2：MyBatis 报错 "Parameter 'userId' not found"

项目使用 ProGuard 混淆时，Mapper 接口方法参数名会被抹掉。修复方式：在 Mapper 参数上加 `@Param("userId")` / `@Param("platform")` 注解。

### Q3：SQLite 数据库在哪？

默认在**启动目录**下的 `data/fvd.db`。`start.bat` 从项目根启动，所以数据库在项目根 `data/` 目录。

### Q4：环境变量改了，后端读取不到？

`.env` 中的 `%VAR%` 展开依赖系统环境变量。修改系统变量后，**必须重启后端进程**（已打开的命令行窗口不会自动继承新变量）。

### Q5：后端报错 "无法加载文件 npm.ps1"

PowerShell 执行策略限制。以管理员身份运行：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

## 六、目录结构速查

```
clipfetch/
├── app.jar              # 部署产物（fat jar）
├── .env                 # 核心配置文件
├── start.bat            # Windows 启动脚本
├── install.bat          # 安装环境变量（管理员）
├── uninstall.bat        # 卸载环境变量（管理员）
├── data/                # SQLite 数据库目录
├── downloads/           # 默认下载目录
├── backend/             # 后端源码（mvn package 产出 jar）
│   ├── src/main/resources/
│   │   ├── application.yml   # 默认配置（.env 优先级更高）
│   │   └── db/migration/     # Flyway 数据库迁移脚本
│   └── target/
│       └── app.jar           # 构建产物（复制到根目录使用）
├── frontend/            # 前端源码（npm run build 产出 dist）
│   └── dist/            # 前端构建产物（用 Nginx 等静态服务器托管）
└── deploy/              # 可选预置工具（yt-dlp/ffmpeg/deno/aria2/jdk21）
```
