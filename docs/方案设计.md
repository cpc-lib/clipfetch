## 2. 技术栈选型

| 层次 | 技术 | 选型理由 |
|------|------|----------|
| 前端框架 | Vue 3.5 + Vite 6 | 轻量、热更新快、组合式 API |
| CSS 框架 | Tailwind CSS 3 | 原子类快速构建，无需大量自定义 CSS |
| HTTP 客户端 | Axios 1.7 | 拦截器统一处理 token 与 401 刷新 |
| 后端框架 | Spring Boot 3.5.4 (Java 21) | 虚拟线程、DDD 分层、生态成熟 |
| 核心能力 | yt-dlp | 1800+ 网站支持，社区活跃 |
| QQ 音乐 | Python 3.11 + Playwright | 浏览器自动化取流，绕过 JS 签名加密 |
| 音视频处理 | ffmpeg | HLS 合并、TS 解密封装 |
| 数据库 | SQLite + HikariCP | 单机部署零配置，Flyway 版本管理 |
| 认证 | JWT (access+refresh) | 无状态，access 120min / refresh 7天 |

## 3. API 设计

> **认证要求**：除 `/api/auth/register`、`/api/auth/login`、`/api/auth/refresh` 外，所有接口均强制 Bearer Token 登录。

### 3.1 解析视频/音频信息

```
POST /api/parse
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}

Response (200):
{
    "success": true,
    "data": {
        "id": "dQw4w9WgXcQ",
        "title": "视频标题",
        "thumbnail": "https://i.ytimg.com/vi/xxx/maxresdefault.jpg",
        "duration": 212,
        "durationString": "3:32",
        "uploader": "上传者名称",
        "platform": "YouTube",
        "formats": [
            {
                "formatId": "137+140",
                "ext": "mp4",
                "resolution": "1920x1080",
                "height": 1080,
                "filesize": 52428800,
                "label": "1080p MP4 (50MB)",
                "needsMerge": false,
                "audioOnly": false,
                "serverOnly": false

        ]
    }
}
```

**支持的平台**：
- **通用**：YouTube、Bilibili、Twitter/X、TikTok、Tubi、BBC、NetMirror 等（yt-dlp 兜底）
- **自研**：抖音、Instagram、CCTV、Missav、Pornhub、**QQ 音乐**
- **QQ 音乐特殊说明**：需先通过 `/api/qqmusic/login` 扫码登录（sidecar 弹窗），非会员歌曲可下载 m4a/mp3，VIP 歌曲返回"无播放权益"错误

### 3.6 Cookies 管理（仅网易云音乐）


## 4. 下载模式策略

系统按平台特性自动选择下载模式：

1. **直链模式**（`serverOnly=false`）：调用 `/api/direct-url` 获取直链，浏览器直接下载
2. **服务端代理模式**（`serverOnly=true`）：调用 `/api/download`，服务端下载后流式传输
   - 普通平台：yt-dlp + aria2c（16 连接分片加速）
   - HLS 平台（CCTV/Tubi/Missav）：yt-dlp native HLS + ffmpeg 封装
   - QQ 音乐：sidecar 取流后直接转发，无需 yt-dlp

## 5. 平台支持与解析策略

| 平台 | 解析方式 | 下载方式 | 特殊说明 |
|------|----------|----------|----------|
| YouTube | yt-dlp | 直链/代理 | 需 deno + PO token + cookies + 代理 |
| 抖音 | 自研(iesdouyin) + yt-dlp 回退 | 服务端代理 | 需用户 cookies |
| Instagram | 自研(页面 JSON 解析) | 服务端代理 | 需用户 cookies |
| Twitter/X | yt-dlp | 服务端代理 | 国内需代理 |
| TikTok | yt-dlp | 服务端代理 | 需 curl_cffi |
| Bilibili | yt-dlp | 直链/代理 | — |
| CCTV | 自研(manifest.hls_h5e_url) | 服务端代理 | h5e 加密由 Java 解密 sidecar 处理 |
| Tubi | 自研(匿名设备 token + CMS v3) | 服务端代理 | 需代理 |
| Missav | 自研(页面 surrit HLS) | 服务端代理 | 需代理 |
| Pornhub | 自研 | 服务端代理 | — |
| **QQ 音乐** | **浏览器 sidecar** | **服务端代理** | **需扫码登录；非会员 m4a/mp3 可取，VIP 104003** |
| 网易云音乐 | 官方 API + weapi 加密 | 服务端代理 | 需上传 cookies；支持 VIP 歌曲 |
| 其他 | yt-dlp | 直链/代理 | 兜底 |

## 6. 前端页面设计

### UI 风格
- 现代简约，粉紫渐变主色调
- 胶囊形按钮（border-radius: 9999px）
- 12px 圆角卡片 + 轻阴影
- 响应式设计，移动端适配

### 页面结构
1. **Header**：Logo + 导航（链接解析 / 字幕转换 / 文件库 / 支持平台）+ 用户菜单
2. **链接解析页（默认页）**：
   - URL 输入框 + 解析按钮
   - 解析结果：封面 + 标题 + 格式选择 + 下载按钮
   - **文件库折叠面板**：解析结果下方可直接展开文件库，无需切换页面
3. **字幕转换页**：字幕上传、编辑、翻译、下载
4. **文件库页**：完整的 temp 表管理（搜索、状态筛选、分页、批量删除）
5. **支持平台区**：各平台 Logo 展示

### 用户菜单
- 点击用户名展开下拉菜单（非纯 hover，避免间隙导致点不到）
- 「我的 Cookies」→ 打开 cookies 管理弹窗
- 「退出登录」

## 8. 认证与授权

### 访问控制
- **强制登录**：所有 `/api/**` 路径（注册/登录/刷新除外）
- **无匿名接口**：`/api/parse`、`/api/download`、`/api/direct-url` 等全部需要 Bearer Token
- **平台差异化**：
  - 网易云音乐解析/下载需上传 cookies（通过「我的 Cookies」弹窗）
  - QQ 音乐需先扫码登录（通过「我的 Cookies」弹窗 → QQ 音乐扫码登录）

## 9. QQ 音乐 Sidecar 设计

### 架构
```
Java (QQMusicBrowserSidecar)
  → 启动 Python HTTP 服务 (qqmusic_sidecar.py)
    → Playwright 启动 Chrome（headless，持久化 profile）
      → 页面注入 init_script 捕获 TmeWebSec SDK
      → 自构 GetEVkey 请求获取直链
```

### 关键配置（application.yml / .env）
```yaml
app:
  python-exe: ${PYTHON_EXE:python}
  qqmusic-sidecar:
    enabled: true
    port: 8095
    profile-dir: D:/data/qqmusic-profile   # Chrome 用户数据目录
```

### 接口
- `GET /health` → 登录状态检测
- `POST /resolve` → 解析歌曲直链（c400/m500/f000 三档）
- `POST /login` → 弹出 Chrome 扫码窗口，轮询登录态

### 约束
- 必须安装 Python 3.10+ 和 `pip install playwright`
- 必须安装系统 Chrome（sidecar 使用 `channel="chrome"`）
- 登录态绑定 Windows 用户（DPAPI 加密），不可跨机器复用 profile
- **无绿钻边界**：非会员歌曲 C400(m4a)/M500(mp3) 可取；VIP 专属 104003；无损 FLAC 需绿钻

## 10. 数据库设计

| 表 | 说明 |
|----|------|
| users | 用户（id, email, password, nickname, is_vip, created_at） |
| refresh_tokens | 刷新令牌（user_id, token, expires_at） |
| user_cookies | 用户 cookies（user_id, platform, content, valid...） |
| temp | 文件库（url, title, source_url, downloaded, **vip**, **deleted**, created_at） |

### temp 表关键字段
- `vip`：Integer，0=免费 1=VIP 会员歌曲 2=付费歌曲（需单独购买）
- `deleted`：逻辑删除标记（@TableLogic），0=正常 1=已删除
- `source_url`：来源链接（歌单/歌手/专辑/单曲原始 URL）
