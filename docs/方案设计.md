## 2. 技术栈选型

| 层次 | 技术 | 选型理由 |
|------|------|----------|
| 前端框架 | Vue 3.5 + Vite 6 | 轻量、上手快、生态成熟 |
| CSS 框架 | Tailwind CSS 3 | 快速构建精美 UI，无需写大量自定义 CSS |
| HTTP 客户端 | Axios 1.7 | 拦截器统一处理 token 与错误 |
| Markdown 渲染 | marked + @tailwindcss/typography | marked 转 HTML + prose 类精美排版 |
| 思维导图 | markmap-lib + markmap-view | 开源成熟，支持 Markdown 输入，交互性好 |
| 后端框架 | Spring Boot 3.5.4 (Java 21) | 企业级生态成熟，DDD 分层清晰，虚拟线程并发 |
| 核心能力 | yt-dlp | 14w+ Star，支持 1800+ 网站，社区活跃 |
| 音视频处理 | ffmpeg | HLS 合并、CCTV TS 解密后封装 |
| AI 大模型 | 通义千问 qwen-plus | OpenAI 兼容协议（百炼端点），中文质量好 |
| 数据库 | MySQL 8 + HikariCP | 用户/Token/Cookies/配额持久化，连接池保活 |
| 认证 | JWT (access+refresh) | 无状态，access 120min / refresh 7天 |
| 实时通信 | SSE + WebSocket | AI 流式输出 / 下载进度推送 |

## 3. API 设计

### 3.1 解析视频信息

```
POST /api/parse
Content-Type: application/json

Request:
{
    "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}

Response (200):
{
    "success": true,
    "data": {
        "id": "dQw4w9WgXcQ",
        "title": "视频标题",
        "thumbnail": "https://i.ytimg.com/vi/xxx/maxresdefault.jpg",
        "duration": 212,
        "durationString": "3:32",
        "uploader": "上传者名称",
        "platform": "YouTube",
        "formats": [
            {
                "formatId": "137+140",
                "ext": "mp4",
                "resolution": "1920x1080",
                "height": 1080,
                "filesize": 52428800,
                "vcodec": "avc1",
                "acodec": "mp4a",
                "label": "1080p MP4 (50MB)",
                "needsMerge": false,
                "audioOnly": false,
                "serverOnly": false
            }
        ],
        "subtitles": ["en", "zh-Hans", "ja"],
        "hasSubtitles": true
    }
}
```

> **说明**：抖音、Instagram 必须登录并上传对应平台 cookies；CCTV、Tubi、Missav、Pornhub 走自研解析器；其余平台走 yt-dlp（登录用户有 cookies 则带上）。

### 3.2 下载视频（服务端代理模式）

```
POST /api/download
Content-Type: application/json

Request:
{
    "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "format_id": "137+140"
}

Response: 视频文件流 (Content-Type: video/mp4)
Headers:
  Content-Disposition: attachment; filename="视频标题.mp4"
```

下载进度通过 WebSocket `/ws/download?taskId=xxx` 实时推送。

### 3.3 获取直链

```
POST /api/direct-url
Content-Type: application/json

Request:
{
    "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "format_id": "137"
}

Response (200):
{
    "success": true,
    "data": {
        "direct_url": "https://rr3---sn-xxx.googlevideo.com/...",
        "ext": "mp4",
        "filesize": 52428800
    }
}
```

> CCTV、Tubi、Missav 等 HLS 流不支持直链，返回 400 提示走服务端下载。

### 3.4 AI 视频总结（SSE 流式）

```
POST /api/summarize
Content-Type: application/json

Request:
{
    "url": "https://www.bilibili.com/video/BV1mAAmzqEfP"
}

Response: SSE 事件流 (Content-Type: text/event-stream)
事件类型：
  - subtitle     → 字幕数据（segments 时间戳 + full_text）
  - summary      → 总结摘要（流式 token，逐字输出）
  - summary_done → 总结完成（完整摘要）
  - mindmap      → 思维导图 Markdown
  - done         → 完成信号
  - error        → 错误信息
```

### 3.5 AI 视频问答（SSE 流式）

```
POST /api/chat
Content-Type: application/json

Request:
{
    "url": "https://www.bilibili.com/video/BV1mAAmzqEfP",
    "question": "这个视频用了什么技术栈？",
    "subtitleText": ""
}

Response: SSE 事件流
  - answer → AI 回答（流式 token）
  - done   → 完成信号
  - error  → 错误信息
```

### 3.6 用户认证

```
POST /api/auth/register    注册
POST /api/auth/login       登录 → { access_token, refresh_token }
POST /api/auth/refresh     刷新 access_token
POST /api/auth/logout      登出
GET  /api/auth/me          当前用户信息（需登录）
```

### 3.7 Cookies 管理

```
GET    /api/cookies          列出当前用户所有平台 cookies
POST   /api/cookies          上传某平台 cookies.txt
DELETE /api/cookies/{platform} 删除指定平台 cookies
```

## 4. 下载模式策略

系统按平台特性自动选择下载模式：

1. **直链模式**（`serverOnly=false`）：调用 `/api/direct-url` 获取直链，浏览器直接下载（不占服务器带宽）
2. **服务端代理模式**（`serverOnly=true` 或直链失败）：调用 `/api/download`，服务端下载后流式传输
   - 普通平台：yt-dlp + aria2c（16 连接分片加速）
   - HLS 平台（CCTV/Tubi/Missav）：yt-dlp native HLS 下载器 + 浏览器模拟请求头
   - CCTV h5e 加密：Node 批量解密 sidecar → ffmpeg 封装 MP4

## 5. 平台支持与解析策略

| 平台 | 解析方式 | 下载方式 | 特殊说明 |
|------|----------|----------|----------|
| YouTube | yt-dlp | 直链/代理 | 需 deno + PO token + cookies + 代理 |
| 抖音 | 自研(iesdouyin) + yt-dlp 回退 | 服务端代理 | 需用户 cookies，CDN 无 attachment 头需代理 |
| Instagram | 自研(页面 JSON 解析) | 服务端代理 | 需用户 cookies，部分 reel 受登录门控 |
| Twitter/X | yt-dlp | 服务端代理 | 国内被墙，需代理 |
| TikTok | yt-dlp | 服务端代理 | 需 curl_cffi，CDN 被墙走代理 |
| Bilibili | yt-dlp | 直链/代理 | — |
| CCTV | 自研(manifest.hls_h5e_url) | 服务端代理 | h5e WASM 加密需 Node 解密 |
| Tubi | 自研(匿名设备 token + CMS v3) | 服务端代理 | 需代理，limit_resolutions 解锁 720p |
| Missav | 自研(页面 surrit HLS) | 服务端代理 | 需代理，yt-dlp impersonate 模拟浏览器 |
| Pornhub | 自研 | 服务端代理 | — |
| 其他 | yt-dlp | 直链/代理 | 兜底 |

## 6. 前端页面设计

### UI 风格
- 现代简约，蓝白主色调
- 主色 `#1777FF`，背景白色 `#FFFFFF`，浅灰区域 `#F8FAFC`
- 胶囊形按钮（border-radius: 9999px）
- 12px 圆角卡片 + 轻阴影
- 响应式设计，移动端适配

### 页面结构
1. **Header**：Logo + 导航（登录/用户菜单）
2. **Hero 区域**：大标题 + 副标题 + URL 输入框
3. **视频面板**（解析成功后显示，左右双栏同屏布局）：
   - **左栏**：缩略图 + 视频元信息 + 格式选择 + 下载按钮 + AI 总结按钮
   - **右栏**：AI 总结面板，4 个 Tab（总结摘要 / 字幕文本 / 思维导图 / AI 问答）
   - 解析成功后自动触发 AI 总结
4. **功能亮点区**：特性卡片
5. **VIP 套餐区**：免费版 vs 高级版
6. **平台展示区**：支持的平台 Logo
7. **Footer**：版权和免责声明

## 8. 认证与授权

### 访问控制
- **强制登录**：`/api/auth/me`、`/api/cookies/**`
- **匿名可选**：`/api/parse`、`/api/download`、`/api/direct-url`、`/api/summarize`、`/api/chat`（有 token 解析用户，无则匿名）
- **平台差异化**：抖音/Instagram 解析时校验用户是否已上传对应平台 cookies

### AI 配额
- 匿名用户：不限制（直接放行）
- 免费用户：每日 3 次 AI 总结/问答
- VIP 用户：不限

## 9. AI 视频总结模块设计

### 9.1 字幕提取策略
- B站视频：专用 API（x/v2/dm/view）获取 CC/AI 字幕，失败回退 yt-dlp
- 其他平台：yt-dlp 提取，优先人工字幕（zh > en > ja > ko），其次自动字幕
- 无字幕 → 返回提示

### 9.2 AI 调用流程
1. 提取字幕文本（截断至 15000 字符）
2. 调用通义千问 qwen-plus（stream=True）流式生成总结摘要
3. 生成思维导图 Markdown
4. SSE 实时推送前端

### 9.3 SSE 数据传输
- `summary`/`answer` 事件：token 经 JSON 编码后发送，避免换行符被 SSE 拆行
- 前端按 SSE 规范处理，`data:` 行用 `\n` 拼接，空行触发事件派发

### 9.4 前端渲染
- **总结摘要**：marked 解析 Markdown → prose 排版 + 流式打字机效果
- **字幕文本**：带时间戳列表，支持下载 SRT/VTT/TXT
- **思维导图**：markmap 渲染 SVG，支持全屏、导出 PNG(4K) 和 SVG
- **AI 问答**：对话式 UI，流式输出 + 光标闪烁
