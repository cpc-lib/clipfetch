## 代码安全限制
- `NativeCheckpointOwnershipLock.requireLocalStorage` 校验 FileStore 网络类型及 UNC 前缀；`VerifiedPieceCheckpoint.commit` 与任务领取都调用。
- 以上拒绝是已知类型的风险缓解，不是 NFS/SMB 的一致性认证。未知 FUSE/网络驱动、符号链接祖先、UNC 映射盘等可能无法被识别；远程路径必须纳入部署层明确禁用策略。
- `NativeExpiredOwnerFenceService` 仅允许查到已停止/过期实例，在 checkpoint 锁内检查并由 CAS 过渡至 PAUSED，审计记录成功/被拒绝事件。
- `@Transactional` 是调用代理时的数据库提交边界；文件锁并未证明在数据库事务实际 COMMIT 之后释放。这是 **自动接管阻断条件**，必须解决后才可以开放。

## 未验收，不应做生产开放
1. **两个完整 Spring Boot 进程 + 共享 MySQL**：真实 Peer Round、心跳续约、崩溃隔离、同一持久目录的再领取及审计回滚尚未端到端验收。
2. **两个独立主机 + NFS/SMB**：没有挂载可用；不可验证断网、缓存一致性、跨主机锁、强制重启后恢复。当前策略为拒绝这类存储而非支持。
3. **数据库事务提交前释放文件锁**：需在文件所有权转移协议中使锁持有到 COMMIT 后（或改成代际独立快照/原子发布协议），并新增 MySQL 两进程受控延迟 COMMIT 测试。
4. **未知网络盘与目录别名**：需要配置层存储根限制及生产部署扫描；不应仅依赖 FileStore.type()。

## 继续验收时的要求
