# P4.63 租约原子 SQL 与数据库 UTC 时钟改造

## 本轮修改
- Mapper 新增 `registerAtomic`、`renewAtomic`、`isLiveAtDatabaseTime`、`isExpiredAtDatabaseTime`，按数据库类型选择 MySQL/SQLite SQL。
- MySQL 在 INSERT/UPDATE 中直接使用 `UTC_TIMESTAMP(6)` 及 `DATE_ADD(UTC_TIMESTAMP(6), INTERVAL 45 SECOND)`，续约 WHERE 也在同一 UPDATE 中使用 `UTC_TIMESTAMP(6)`，取消读时间后再更新的竞态窗口。
- SQLite 使用 `STRFTIME('%Y-%m-%d %H:%M:%f','now')` 与 `+45 seconds`，兼容旧数据 `T` 格式的隔离判断用 `REPLACE(lease_until,'T',' ')`。
- 心跳执行与手工过期隔离已接入新接口。健康及过期 SELECT 继续强制绕开 MyBatis 缓存。
- MySQL 时钟函数直接返回 UTC，不依赖会话 time_zone；由于现有 task/审计等其它日期字段未一并更改，生产仍需检查应用 MySQL 会话时区及数据库字段定义的一致性。
