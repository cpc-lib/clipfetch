日期 2026-10-15。隔离 Windows 主机、Docker MySQL 8.0，本次启动两个完整 Spring Boot Jar，临时监听 18821、18822；禁止 Native Download/Worker Round/自动接管。

## 已执行与通过
- 隔离 MySQL 创建并执行 Native 数据库迁移 V13/V19/V20/V21。
- 真实 Java 双 JVM MySQL JDBC 提交前中断、提交后可见性、事务回滚与审计结果（P4.56）。
- 本轮增强：子 JVM 使用 Spring `DataSourceTransactionManager` + `TransactionTemplate(REQUIRES_NEW)`，在同一 Checkpoint FileLock 内进行任务 CAS+审计；`SPRING_CRASH` 验证数据库回滚（RUNNING:2:1:0），`SPRING_COMMIT` 验证提交后可见性（PAUSED:3:1:1）；专项测试 Exit Code 0。
- 实际使用两个完整 Spring Boot JAR 连接同一 MySQL，初次暴露 `NativeExpiredOwnerFenceService` 双构造器未标记注入，两个服务启动失败；给生产构造器添加 `@Autowired` 后 18821、18822 均启动成功并向 `torrent_native_worker_instance` 注册不同 ACTIVE 实例。
- 真实 heartbeat 续期：两实例 `lease_until` 经过 17 秒检查均更新，说明 `@Scheduled` 心跳在两个完整 Boot 进程有效。
- 已有守卫：NFS/SMB/UNC 已知网络共享存储拒绝；无自动下载及接管启用。

## 阻断项与未做
- **未验证**两个完整 Spring Boot 的 Native Worker 下载、网络 Peer Piece IO、同一下载任务实际转移；本轮 Boot 双实例均明确禁止 Worker Round。
- **未验证**完整 Spring Boot 内部的 `NativeExpiredOwnerFenceService` RPC/命令触发迁移（目前仅独立 Spring TransactionTemplate 子 JVM 覆盖）。

- 生产自动接管必须继续关闭。
